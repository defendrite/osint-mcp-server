# osint-mcp-server

OSINT MCP Server

Build and Run

```bash
cargo build --release
npx @modelcontextprotocol/inspector ./target/release/osint-mcp-server
```

## Technologies

- Rust
- rmcp
- Tokio
- Serde
- Model Context Protocol (MCP)
